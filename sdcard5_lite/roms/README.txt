Game Boy / Game Boy Color / Game Boy Advance ROMs
=================================================
Copy your own .gb / .gbc / .gba cartridge dumps here (sub-folders are fine). The Game Library
(Onyx menu > Games > Game Library) lists them; opening one in the File Viewer starts the
emulator (gbemu, gbaemu). Battery saves are written beside each ROM as <name>.sav.
No ROM is shipped with Onyx.
