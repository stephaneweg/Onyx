# Pocket application -- la liste des choses a faire (todo.txt du dossier : texte <tab> echeance <tab> duree <tab> prevue).
# Deux statuts : a faire (une idee, pas encore placee) et prevue (placee dans l'agenda a une date). Faite ou plus
# necessaire : supprimee (done).
name = A faire
category = Organisation
description = la liste des choses a faire
llm.add = texte [texte] [date] : ajouter une chose a faire quand la personne dit qu'elle doit faire quelque chose sans jour ni heure de rendez-vous (je dois appeler le plombier) ; puis la duree si elle est dite (deux heures, un apres-midi ; "" sinon) ; puis l'echeance seulement si elle donne un delai (avant vendredi) ; une chose par appel
llm.plan = texte date [heure] : marquer une chose a faire comme prevue a ce jour (quand tu la places dans l'agenda : agenda write puis todo plan) ; elle reste dans la liste, prevue, jusqu'a ce qu'elle soit faite
llm.done = texte : supprimer une entree quand la tache est faite ou n'est plus necessaire (j'ai tondu la pelouse, laisse tomber la porte) ; jamais quand elle est seulement planifiee : alors todo plan ; quelques mots qui la designent
llm.list = [date] : dire la liste : d'abord ce qui est a faire et pas encore prevu (avec la duree : c'est ce qu'il faut planifier quand la personne a du temps libre), puis ce qui est deja prevu (ne pas le replanifier) ; avec une date : seulement ce qui est a faire avant ce jour
llm.edit = texte texte [texte] [date] : changer une chose a faire (les mots qui la designent, le nouveau texte, la duree, l'echeance ; "" pour ne pas changer)
llm.clear = : vider toute la liste, seulement si la personne le demande clairement
cron = list
