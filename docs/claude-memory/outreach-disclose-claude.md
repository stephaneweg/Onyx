When writing anything that presents Onyx to the outside (emails to the press, forum posts, article pitches, README), say up front that it is built by Stephan Wegener working with Claude, with much of the code written by Claude under his direction. Do not write "I am the developer / written from scratch" alone.

**Why:** on 2026-10-05 the first press emails omitted it; Liam Proven (The Register) answered "implausibly quick... built by LLM?". The user answered honestly and agreed to state it in the README ("How it is built") and in follow-ups.

**How to apply:** the user's description of his role: he brings the architecture and the direction, sometimes guides step by step, sometimes asks Claude's opinion (it researches faster), sometimes supplies articles and example links; see [[mockup-first-for-apps]]. Emails already sent (2026-10-05): framboise314, Minimachines, Programmez!, Hackable, GNU/Linux Magazine, Raspberry Pi Official Magazine, Hackaday, The Register, OSNews.
