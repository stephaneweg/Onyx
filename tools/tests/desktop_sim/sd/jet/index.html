Jet Browser

The web browser of Onyx, based on NetSurf

The padlock

Left of the address: green for a secure page, red past a certificate warning. Click it to see the certificate.

The site's version

Right of the address: Standard, Mobile or Desktop, for each site. The page is loaded again with the version chosen.

A fast network

TLS 1.3, HTTP/2, brotli and zstd, a disk cache in RAM: and the TLS sessions kept between launches.

Zoom, downloads

Ctrl+ and Ctrl- (or the - 100% + control): the page larger or smaller, kept for each site. Files are saved in SD:/Downloads.

Find, copy

Ctrl+F finds words in the page. A right click copies a link, or an image for Paint.
